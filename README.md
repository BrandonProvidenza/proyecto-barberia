# Barbería Videnz

Sitio web de Barbería Videnz, desarrollado como proyecto de Coderhouse.

## Tecnologías utilizadas

- HTML5
- CSS3
- Sass (SCSS)
- Bootstrap 5
- JavaScript
- AOS para animaciones

## Páginas del sitio

- Inicio
- Nosotros
- Servicios
- Galería
- Contacto
